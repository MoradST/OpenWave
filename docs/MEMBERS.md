# 👋 OpenWave Members

Meet the people, organizations, communities and brands who want to be part of OpenWave.

**Members are profiles, not a topic channel.** They have their own area so introductions don't clutter the stream of updates.

## Explore

- [People — Member profiles](https://github.com/MoradST/OpenWave/issues?q=is%3Aissue+in%3Atitle+%22%5BMember%5D%22)
- [Brands and organizations](https://github.com/MoradST/OpenWave/issues?q=is%3Aissue+in%3Atitle+%22%5BBrand%5D%22)
- [All profiles](https://github.com/MoradST/OpenWave/issues?q=is%3Aissue+in%3Atitle+%22%5BMember%5D%22+OR+%22%5BBrand%5D%22)

## Introduce yourself

- [Create a personal profile](https://github.com/MoradST/OpenWave/issues/new?template=member.yml)
- [Create a brand/organization profile](https://github.com/MoradST/OpenWave/issues/new?template=brand.yml)

A GitHub login is required. Each submitted profile becomes a public GitHub Issue immediately, with no OpenWave pre-publication approval. Users can edit their own issue, and everyone can reply in the comments, subject to GitHub permissions.

## Via ChatGPT

If your ChatGPT has a GitHub connection with permission to create Issues, try:

> In MoradST/OpenWave, create a GitHub Issue with the title "[Member] Your display name". The body should start with "Profile type: member" and include my self-introduction, interests and links. Ask me for missing details; do not invent facts. Return its URL.

For an organization, use the title prefix `[Brand]` and `Profile type: brand`.

To find someone:

> Search issues in MoradST/OpenWave with "[Member]" in their titles and summarize the introductions with links. Keep brand profiles separate.

## Open by default, not verified

Profiles are created by GitHub users, **not verified identities**. A profile describing a company does not prove the poster represents that company; do not treat profiles as endorsements, identity verification, or official channels. Never share secrets, private personal information, or another person's location.

If the directory becomes large, we'll move toward a purpose-built searchable directory while keeping public links stable.
